# AI 면접 코치

선택한 산업 분야와 직군에 맞춰 신입 면접을 연습하는 Streamlit 서비스입니다. 면접 다섯 질문과 질문당 한 번의 꼬리 질문을 거쳐 네 위원의 평가, 재도전, 마지막 질문 개선, 마크다운 리포트를 제공합니다. 실제 개인정보와 회사 기밀은 입력하지 마세요.

## 화면별 프롬프트 기법

- 준비: ⑭ 컨텍스트로 회사·직군·경험을 제공하고 ③ 페르소나로 면접관을 정합니다. PO 외의 페르소나는 직접 채워 주세요.
- 면접: ⑧ 게임 플레이로 면접 역할을 수행하고 ⑤ 숫자 규칙으로 질문과 꼬리 질문을 제한합니다.
- 평가: ⑮ 다중 관점의 네 위원이 ⑯ 반론 먼저 평가합니다. ⑫ 리플렉션으로 답변을 돌아보고 ⑩ 팩트 체크로 확인할 사실을 표시합니다.
- 재도전: BAB(전·후·차이)로 점수와 기준별 변화를 비교합니다.
- 마지막 질문: ⑨ 질문 개선으로 회사·직무·성장 관점의 질문을 만듭니다.

## 실행

프로젝트 폴더에서 `pip install -r requirements.txt`를 실행하세요. `.env.example`을 참고해 직접 `.env`를 만들고 `OPENAI_API_KEY=키`와 `OPENAI_MODEL=gpt-6-luna`를 입력하세요. 선택적으로 `OPENAI_EVAL_MODEL`을 지정하면 평가에만 해당 모델을 사용합니다. 키 파일은 공유하거나 커밋하지 마세요.

```bash
streamlit run app.py
```

## Streamlit Community Cloud 배포

GitHub 저장소에 이 폴더의 파일들을 올리고 Streamlit Community Cloud에서 해당 저장소, 브랜치와 `app.py`를 선택합니다. 배포 화면의 Advanced settings → Secrets에 아래 TOML 형식으로 값을 직접 입력하세요. 실제 키는 채팅이나 저장소에 올리지 마세요.

```toml
OPENAI_API_KEY = "여기에 직접 입력"
OPENAI_MODEL = "gpt-6-luna"
```

앱은 방문자가 AI 기능을 사용할 때 설정된 계정으로 API를 호출합니다. 공유 범위와 API 사용량을 확인한 후 배포하세요. 면접 기록은 현재 브라우저 세션에만 유지됩니다.
